# WI-007 — Playwright end-to-end tests

- Status: Done
- Work-track: [WT-01](../work-tracks/WT-01-project-boilerplate.md)
- Depends on: WI-005
- Work-spec: [WS-007](../work-specs/WS-007-e2e.md)

## Outcome

`pnpm test:e2e` builds the app, starts it against its own database, and drives it through
a real browser and real HTTP requests. This is the last of the five quality gate commands
in `AGENTS.md` section 5, and the level at which later work-tracks will prove complete
user and agent flows.

## Acceptance criteria

- [x] `pnpm test:e2e` needs only a running database: it builds and starts the app by
      itself and stops it afterwards.
- [x] The tests run against the production build, not the development server.
- [x] A browser test confirms the home page shows the "Opanel" heading.
- [x] HTTP-level tests confirm `GET /api/v1/health` returns `200` with the documented body
      and `GET /api/v1/openapi.json` returns a document listing the health endpoint.
- [x] End-to-end tests use a database of their own, separate from the development and
      integration-test databases.
- [x] `pnpm test` (Vitest) does not run the end-to-end tests, and `pnpm test:e2e` does not
      run the Vitest tests.
- [x] A deliberately broken expectation makes `pnpm test:e2e` fail (verified once).
- [x] The full existing quality gate passes.

## Notes

Only the Chromium browser is configured in this item.
